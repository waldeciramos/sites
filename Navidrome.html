Navidrome no Debian

Um Spotify particular, rodando no seu servidor. Você aponta para a pasta de músicas, o Navidrome organiza tudo e libera um player web bonito — acessível de qualquer lugar, sem mensalidade.

~15 minutos
Via Docker Compose
Dificuldade: fácil

O que você vai ter no fim

O Navidrome lê a sua biblioteca de música, organiza por artista/álbum/gênero e entrega tudo por um player web moderno — além de falar o protocolo Subsonic, então funciona com dezenas de apps de celular prontos.

Sua biblioteca, organizada

Lê metadados, capas e letras automaticamente e reindexa sozinho quando você adiciona músicas.

Multiplataforma

Player web embutido, mais compatibilidade Subsonic/OpenSubsonic para apps de Android, iOS e desktop.

Leve de verdade

Container único, baixo consumo de RAM — roda tranquilo ao lado do resto da sua stack (Nginx, MariaDB, AzuraCast).

Antes de começar

Isso aqui parte do princípio de que você já tem um Debian rodando e acesso SSH — igual ao seu setup atual.

  • Acesso root ou sudo ao servidor Debian, via SSH.
  • Docker + Docker Compose instalados — o passo 1 mostra como instalar se ainda não tiver.
  • Sua pasta de músicas pronta para copiar (MP3, FLAC, etc.) via WinSCP, MobaXterm ou scp.
  • Porta 4533 livre no servidor (ou domínio + Nginx, se for expor por fora).

Instalação passo a passo

Todos os comandos são para colar direto no terminal SSH do seu Debian.

1

Instalar o Docker (se ainda não tiver)

Primeiro confira se o Docker já está instalado no servidor:

bash 
docker --version
docker compose version

Se der "command not found", instale com o script oficial (já traz o plugin do Compose junto):

bash 
curl -fsSL https://get.docker.com | sudo sh
sudo usermod -aG docker $USER
Importante: depois do usermod, saia e entre de novo no SSH (ou rode newgrp docker) para o grupo valer.
2

Criar a estrutura de pastas

Um diretório para os dados do Navidrome (banco, cache) e outro para a sua biblioteca de música:

bash 
sudo mkdir -p /opt/navidrome/data /opt/navidrome/music
sudo chown -R $USER:$USER /opt/navidrome
cd /opt/navidrome
3

Criar o docker-compose.yml

Abra um arquivo novo:

bash 
nano docker-compose.yml

E cole este conteúdo:

yaml 
services:
  navidrome:
    image: deluan/navidrome:latest
    container_name: navidrome
    restart: unless-stopped
    ports:
      - "4533:4533"
    environment:
      ND_SCANSCHEDULE: 1h
      ND_LOGLEVEL: info
      ND_SESSIONTIMEOUT: 24h
    volumes:
      - ./data:/data
      - ./music:/music:ro

Salve com Ctrl+O, Enter, e saia com Ctrl+X.

4

Subir o container

bash 
docker compose up -d
docker compose logs -f

Quando o log mostrar algo como Navidrome server listening, tá no ar. Pode sair do log com Ctrl+C — o container continua rodando em segundo plano.

5

Copiar sua biblioteca de música

Use o mesmo fluxo que você já usa hoje: WinSCP ou MobaXterm, jogando os arquivos direto em /opt/navidrome/music. Se preferir por linha de comando de outra máquina Linux:

bash · rodar na sua máquina, não no servidor 
scp -r ./MinhasMusicas/* usuario@192.168.2.70:/opt/navidrome/music/
O Navidrome reescaneia a pasta sozinho a cada hora (ND_SCANSCHEDULE: 1h). Para forçar agora, use o botão de scan dentro da interface web, em Configurações.
6

Acessar e criar o usuário admin

Abra no navegador: http://SEU_IP_DO_SERVIDOR:4533 — por exemplo http://192.168.2.70:4533. Na primeira vez, o Navidrome pede para você criar a conta de administrador.

Opcional: expor com domínio via Nginx

Como você já tem Nginx rodando nos seus servidores, dá pra colocar o Navidrome atrás de um domínio próprio em vez de usar IP:porta.

/etc/nginx/sites-available/navidrome 
server {
    listen 80;
    server_name musica.seudominio.com;

    location / {
        proxy_pass http://127.0.0.1:4533;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}

Ative o site e peça o certificado SSL:

bash 
sudo ln -s /etc/nginx/sites-available/navidrome /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
sudo certbot --nginx -d musica.seudominio.com
Só funciona se musica.seudominio.com já estiver apontando (registro A) pro IP público desse servidor.
Caminho alternativo

Instalando a partir da pasta baixada do GitHub

Se você já tem o navidrome-master.zip baixado do repositório em vez de puxar a imagem pronta do Docker Hub, tem dois jeitos de seguir a partir dele.

Qual escolher: a Opção A reaproveita o Docker que você acabou de configurar e é a mais tranquila de manter. A Opção B compila o binário direto no Debian, sem Docker — só vale a pena se você quer mexer no código ou não quer depender de container.

Opção A · Build da imagem Docker localmente

Envie o navidrome-master.zip para o servidor (WinSCP/scp) e extraia dentro da pasta do projeto:

bash 
cd /opt/navidrome
unzip navidrome-master.zip
cd navidrome-master
docker build -t navidrome:local .

Essa primeira build baixa toolchain de Go, Node e ferramentas de cross-compile — pode levar alguns minutos na primeira vez. Depois, é só apontar o seu docker-compose.yml (o mesmo do passo 3) para a imagem local em vez da imagem do Docker Hub:

docker-compose.yml · trecho alterado 
services:
  navidrome:
    image: navidrome:local   # em vez de deluan/navidrome:latest
    container_name: navidrome
    restart: unless-stopped
    ports:
      - "4533:4533"
    volumes:
      - ./data:/data
      - ./music:/music:ro
bash · aplicar 
cd /opt/navidrome
docker compose up -d

Opção B · Compilar nativamente (sem Docker)

O projeto pede Go 1.27+ e Node 24. O Debian estável costuma trazer versões mais antigas nos repositórios, então instalamos direto do site oficial de cada um.

1. Dependências de sistema

bash 
sudo apt update
sudo apt install -y build-essential git curl

2. Go 1.27+

bash 
curl -LO https://go.dev/dl/go1.27.1.linux-amd64.tar.gz
sudo rm -rf /usr/local/go
sudo tar -C /usr/local -xzf go1.27.1.linux-amd64.tar.gz
echo 'export PATH=$PATH:/usr/local/go/bin' >> ~/.bashrc
source ~/.bashrc
go version
Confira a versão mais recente em go.dev/dl antes de rodar — o link do .tar.gz muda a cada release.

3. Node.js 24

bash 
curl -fsSL https://deb.nodesource.com/setup_24.x | sudo -E bash -
sudo apt install -y nodejs
node -v

4. Compilar

bash 
cd /opt/navidrome/navidrome-master
make build

Isso gera um binário navidrome na raiz do projeto. Para testar na hora:

bash 
./navidrome --music-folder /opt/navidrome/music --data-folder /opt/navidrome/data --port 4533

5. Deixar rodando sempre (systemd)

bash 
sudo tee /etc/systemd/system/navidrome.service > /dev/null <<'EOF'
[Unit]
Description=Navidrome Music Server
After=network.target

[Service]
User=SEU_USUARIO
ExecStart=/opt/navidrome/navidrome-master/navidrome --music-folder /opt/navidrome/music --data-folder /opt/navidrome/data --port 4533
Restart=on-failure

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl daemon-reload
sudo systemctl enable --now navidrome

Troque SEU_USUARIO pelo seu usuário no Debian. Depois confira com sudo systemctl status navidrome.
