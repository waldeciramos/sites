O que ainda precisa de internet mesmo no modo interno: clima, rádios (Radio Swiss), notícias automáticas, vídeos do YouTube e as fontes do Google. Fotos, vídeos enviados, programação, frases e recados funcionam sem internet.

1. Instalar no servidor Debian

Serve para Debian 12 ou 13. Você precisa de acesso ao servidor por SSH (ou no teclado dele) e de um usuário com sudo.

1.1 Levar o pacote até o servidor

No computador onde está o clinicatv.zip (troque usuario e IP-DO-SERVIDOR):

scp clinicatv.zip usuario@IP-DO-SERVIDOR:~

No Windows, pode usar o WinSCP ou um pendrive.

1.2 Descompactar e instalar

sudo apt update && sudo apt install -y unzip
unzip clinicatv.zip
cd clinicatv
sudo bash instalar-debian.sh

O instalador: instala o Node.js, cria o usuário do serviço, copia tudo para /opt/clinicatv, pergunta a senha do painel (usuário admin), cria o serviço que liga sozinho com o servidor e mostra os endereços no final. Opções úteis:

sudo bash instalar-debian.sh --porta 8080                 # em vez da porta 80
sudo bash instalar-debian.sh --rede 192.168.2.0/24        # liga o firewall liberando só essa rede
sudo bash instalar-debian.sh --senha NovaSenha            # troca a senha
Cuidado com --rede: ela liga o firewall (ufw) e libera SSH e site apenas para a rede informada. Use só se você acessa o servidor de dentro dessa rede; se acessar por VPN ou de outra rede, não use e configure o firewall à mão.

1.3 Conferir

systemctl status clinicatv          # deve mostrar "active (running)"
curl http://localhost/api/ping      # deve responder {"clinicatv":true,...}
journalctl -u clinicatv -n 50       # últimas mensagens do serviço

Pronto. No navegador de qualquer aparelho da rede: http://IP-DO-SERVIDOR/ (TV) e http://IP-DO-SERVIDOR/admin.html (painel).

Dica: deixe o servidor com IP fixo (ou reserve o IP no roteador) para o endereço da TV nunca mudar.

2. Abrir na TV

A TV (ou o mini PC ligado por HDMI) só precisa abrir o endereço do servidor em tela cheia. Para a rádio tocar sozinha e o YouTube com som, o navegador precisa da opção de autoplay.

Windows (Chrome ou Edge)

Crie um atalho com este destino e coloque-o em shell:startup para abrir junto com o Windows:

"C:\Program Files\Google\Chrome\Application\chrome.exe" --kiosk --autoplay-policy=no-user-gesture-required --noerrdialogs --disable-infobars http://IP-DO-SERVIDOR/

Linux com tela (Chromium)

chromium --kiosk --autoplay-policy=no-user-gesture-required --noerrdialogs --disable-infobars http://IP-DO-SERVIDOR/

No Debian com sudo apt install chromium, o navegador já toca vídeos MP4 (H.264). Atenção: alguns Chromium de outras origens (por exemplo, builds sem codecs) não tocam H.264; veja "Problemas".

Teclas na TV: F tela cheia · R girar a tela · M liga/pausa a rádio · N próxima rádio. Para sair do modo quiosque: Alt+F4.

Monitor ligado no próprio servidor (opcional)

Esta parte não foi testada no meu ambiente; use o PC/TV com navegador (acima) se puder. Em um servidor só com terminal, dá para usar o cage (mini ambiente gráfico) com o Chromium: sudo apt install cage chromium e, no console do servidor, cage -- chromium --kiosk --autoplay-policy=no-user-gesture-required http://localhost/. Para iniciar sozinho no boot é preciso criar um serviço de login automático; me peça que eu monto esse passo a passo.

3. Usar o painel

  1. Abra http://IP-DO-SERVIDOR/admin.html e entre com admin e a senha da instalação.
  2. À direita há a pré-visualização ao vivo. Em cada propaganda existe o botão 👁 Ver só esta para ver somente ela.
  3. Tudo que você muda é salvo na hora e a TV atualiza sozinha.
  4. Troque a senha em Publicar e Backup → Usuário e senha do admin.

Abas principais: Identidade (logo da clínica na coluna lateral, cores, fontes), Clima e Local, Tela e Layout, Propagandas (imagem, vídeo, YouTube, zonas, texto), Programação, Frases, Rodapé (notícias), Rádio.

Vídeos e fotos (tudo interno)

Em Propagandas → Nova propaganda escolha Imagem ou Vídeo e use Enviar do computador. Os arquivos ficam em /opt/clinicatv/midia/ e passam a aparecer na lista "…ou da pasta midia". Também dá para copiar arquivos direto para essa pasta:

sudo cp meu-video.mp4 /opt/clinicatv/midia/ && sudo chown clinicatv: /opt/clinicatv/midia/*

Formato de vídeo que toca em qualquer TV: MP4 com vídeo H.264 e áudio AAC (não use H.265/HEVC). Para converter qualquer vídeo (celular, WhatsApp etc.):

sudo apt install -y ffmpeg
bash converter-video.sh meu-video.mov

O script também oferece criar um .webm com o mesmo nome. Se o navegador da TV não souber tocar o MP4, ele usa esse .webm sozinho. Fotos: JPG ou PNG de até 1920 px ficam leves e nítidas.

Vídeo MP4 com duração 0 toca até o fim e depois a TV volta aos slides. Se um vídeo não abrir, aparece um aviso vermelho no canto da tela explicando o motivo (e a TV passa para o próximo).

Vídeos do YouTube

Em Propagandas, escolha o tipo ▶ YouTube e cole o link (youtu.be, youtube.com/watch, shorts). Com duração 0 o vídeo toca até o fim e a TV volta aos slides; com um número maior que 0, ele é cortado nesse tempo. É possível começar em um segundo específico e (com a opção de autoplay do navegador) tocar com som.

Precisa de internet na TV. Alguns vídeos não permitem ser exibidos em outros sites: nesse caso a TV mostra um aviso e passa para o próximo. Se o YouTube não responder, a publicação usa só o tempo definido.

Zonas: montar a tela com vários quadros

Em Propagandas → Nova propaganda → Tipo "🧩 Zonas":

  1. Clique em um modelo pronto (2 colunas, 1 grande + 2 pequenas, 4 quadros…) ou em + Imagem / + Vídeo / + YouTube / + Texto.
  2. Arraste cada quadro para mover; puxe as bolinhas amarelas dos cantos para mudar o tamanho. Use o "Ímã" para alinhar.
  3. Com a zona selecionada, escolha o conteúdo (enviar arquivo, caminho, link do YouTube ou texto), cantos arredondados, borda e sombra.
  4. Em Quando passar para o próximo: "pelo tempo" ou "quando o 1º vídeo terminar".

As medidas são em % da tela central, então funcionam em TV, monitor e totem. Zonas mais acima na lista ficam na frente (botões "trazer para frente" e "enviar para trás").

Tela central em zonas fixas (mosaico)

Na aba 🧩 Tela em zonas escolha "Zonas fixas". A tela central passa a ficar dividida em 1, 2, 3, 4, 6 ou mais zonas ao mesmo tempo. Cada zona do tipo 🎞 Lista tem a sua própria sequência de imagens e vídeos, que passa sozinha e independente das outras zonas. Para cada item você escolhe os segundos (vídeo com 0 toca até o fim), o ajuste (preencher, inteiro ou esticar) e se toca com som (pausa a rádio). Voltando para "Slides", a TV volta a mostrar uma propaganda por vez.

Deixar só na rede interna

  • O servidor não precisa de porta aberta para a internet: não faça redirecionamento de porta no roteador para ele.
  • Para travar o acesso à sua rede, use --rede 192.168.2.0/24 no instalador (troque pela faixa da sua rede) ou configure o ufw à mão.
  • Só quem entra no painel com a senha consegue alterar a TV; qualquer aparelho da rede consegue ver a TV.
  • Os arquivos de senha e o código do servidor não são entregues pelo site.

Backup, atualização e remoção

Backup (configurações + mídias)

sudo tar czf clinicatv-backup-$(date +%F).tar.gz -C /opt/clinicatv dados midia

Restaurar

sudo systemctl stop clinicatv
sudo tar xzf clinicatv-backup-AAAA-MM-DD.tar.gz -C /opt/clinicatv
sudo chown -R clinicatv: /opt/clinicatv/dados /opt/clinicatv/midia
sudo systemctl start clinicatv

Atualizar para uma versão nova

Descompacte o novo pacote e rode sudo bash instalar-debian.sh de novo. As configurações (dados/), a senha e as mídias enviadas são mantidas.

Trazer a configuração antiga

No painel antigo: Publicar e Backup → Baixar config.json. No novo: Importar config.json.

Remover

sudo systemctl disable --now clinicatv
sudo rm /etc/systemd/system/clinicatv.service /etc/clinicatv.env
sudo rm -r /opt/clinicatv && sudo userdel clinicatv

Problemas comuns

Vídeo não apareceVeja o aviso vermelho no canto da TV. "Formato não suportado": converta com converter-video.sh (H.264 + AAC) e, de preferência, gere também o .webm. Confira também se o navegador da TV é o Chromium/Chrome do Debian (com codecs). No painel, a propaganda de vídeo mostra "✔ Vídeo OK" ou o motivo do erro.
Rádio não toca sozinhaO navegador bloqueia som automático. Abra com --autoplay-policy=no-user-gesture-required (veja "Abrir na TV") ou toque uma vez na tela.
Gráfico da rádioUsa o sinal real do som quando a rádio permite; se não permitir, anima sozinho. Ele nunca fica parado, mesmo com a rádio pausada (movimento suave).
Painel diz "sessão expirada"Saia e entre de novo (a sessão vale 12 horas ou até reiniciar o serviço).
Porta 80 em usoOutro serviço (Nginx/Apache) usa a porta. Reinstale com --porta 8080 ou desligue o outro serviço.
Não abre de outro aparelhoConfira o IP (hostname -I), o firewall (sudo ufw status) e se está na mesma rede.
Fontes Qurova/AgencyCopie os arquivos Qurova.woff2 e Agency.woff2 para /opt/clinicatv/fontes/ (confira a licença). Sem eles usa fontes parecidas.

Usar também no GitHub Pages

  1. Crie um repositório e envie estes arquivos/pastas: index.html, admin.html, acesso.json, config.json, logo.svg, assets/, fontes/, midia/. (Pode enviar o server.js junto: ele não atrapalha.)
  2. Settings → Pages → Branch main / (root) → Save.
  3. TV: https://SEU-USUARIO.github.io/SEU-REPO/ · Painel: .../admin.html (usuário e senha em acesso.json; troque a senha padrão e prefira repositório privado).
  4. Para atualizar as TVs: Painel → Publicar e Backup → Baixar config.json → substitua o arquivo no repositório. Elas atualizam em até 2 minutos (modo "Do arquivo config.json").
  5. Fotos e vídeos: coloque os arquivos na pasta midia/ do repositório e use o caminho midia/arquivo.jpg. O GitHub limita arquivos a 100 MB; prefira vídeos leves.
