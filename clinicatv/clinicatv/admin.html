Editor de zonas (layout livre)

Arraste e redimensione os blocos para montar a tela. Cada zona corresponde a um elemento da TV. Salva automaticamente no config.json.

Arraste o centro para mover. Arraste o canto inferior direito para redimensionar. Duplo-clique para renomear.

Publicar, backup e segurança

✔ Modo servidor Debian: tudo que você altera é salvo no servidor e as TVs atualizam sozinhas em segundos.
⚠ A senha padrão é admin123. Troque abaixo.

Como a TV lê os dados (GitHub Pages)

  1. Faça as alterações aqui no admin.
  2. Clique em Baixar config.json.
  3. No GitHub, substitua o config.json do repositório.
  4. Nas TVs, deixe "Do arquivo config.json".
