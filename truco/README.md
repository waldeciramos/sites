# Truco Waldeci

Ideia original: **Truco Waldeci**.

Jogo de truco mineiro para 2 ou 4 jogadores, em HTML, CSS e JavaScript puros (sem instalar nada).

## Arquivos
- `index.html`: telas, manuais e histórico
- `style.css`: visual com modo claro e escuro
- `game.js`: regras, bots, apostas, voz e histórico

## Publicar no GitHub Pages
1. Crie um repositório e envie os 4 arquivos para a raiz.
2. Em **Settings > Pages**, escolha a branch `main` e a pasta `/ (root)`.
3. Abra o endereço que o GitHub mostrar.

## Dados salvos
O histórico fica no navegador de cada aparelho (celular ou PC). Use **Histórico > Exportar** para baixar um arquivo.

## Online
Crie uma sala e mande os códigos aos outros jogadores: o código terminado em P é do parceiro e o terminado em X, dos adversários. Veja o passo a passo em `implantacao.html`.
