Truco Waldeci

Ideia original: Truco Waldeci. Este guia mostra como colocar o jogo no ar e como jogar online com 4 pessoas.

1. Publicar no GitHub

  1. Crie uma conta gratuita em github.com.
  2. Clique em New repository, dê o nome truco-waldeci e marque Public.
  3. Extraia o arquivo ZIP e, no repositório, use Add file > Upload files para enviar os arquivos: index.html, style.css, game.js, online.js, implantacao.html e README.md. Clique em Commit changes.
  4. Vá em Settings > Pages. Em Branch, escolha main e a pasta / (root). Clique em Save.
  5. Espere 1 a 2 minutos. O GitHub mostra o endereço, parecido com seu-usuario.github.io/truco-waldeci. Esse é o link do jogo.

2. Jogar online com 4 pessoas

  1. O anfitrião (jogador 1) abre o link, escolhe 4 jogadores e o modo de manilha, preenche nome e avatar e toca em Criar sala online.
  2. O jogo mostra dois códigos de 5 caracteres. O que termina em P é do parceiro dele. O que termina em X é para os dois adversários.
  3. O anfitrião manda os códigos pelo WhatsApp. Cada um abre o mesmo link, preenche nome e avatar, digita o código em Entrar numa sala e toca em Entrar.
  4. Quem digita o código P vira parceiro do anfitrião. Os dois que digitam o código X formam a dupla adversária.
  5. Quando todos aparecerem na lista, o anfitrião toca em Começar o jogo. Vaga que ficar livre é ocupada por um bot.

Para 2 jogadores, vale só um código (terminado em X) para o adversário.

3. Como a conexão funciona

O celular do anfitrião roda o jogo. Ele embaralha e manda para cada pessoa só as cartas dela. Na mão de onze, o parceiro também recebe as cartas do colega. A conexão é direta entre os aparelhos, por WebRTC com PeerJS, e funciona entre cidades e países.

4. Cuidados e problemas comuns

  • Se o anfitrião fechar a página, a partida acaba. Peça para ele manter a tela ligada.
  • Se alguém cair da conexão, um bot assume o lugar dele.
  • Se alguém não conseguir entrar, confira o código (letras maiúsculas) e tente trocar de wi-fi para 4G. Algumas redes bloqueiam a conexão direta.
  • O reconhecimento de voz funciona melhor no Chrome. O botão de truco sempre funciona.
  • O histórico fica salvo só no aparelho de cada pessoa. Use Histórico > Exportar para guardar.

5. Atualizar o jogo

Para mudar algo, substitua o arquivo no repositório (Add file > Upload files) e confirme. A página atualiza em alguns minutos. Se o navegador mostrar a versão antiga, recarregue a página.
